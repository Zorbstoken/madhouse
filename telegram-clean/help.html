Plain words. Tap, do not type.

❓ How to open this Dashboard

1. Open the fresh bot in Telegram (not the old @Zorbianbot).

2. Tap the menu button, or tap Open Dashboard in the bot's first message.

3. The Dashboard opens inside Telegram. Use the bottom menu: Dashboard, Compass, Control, Site Map, Games, Map.

Telegram does not let a bot open a WebApp with zero taps when you first open the chat. One tap on the menu button or the Open Dashboard button is the real one-tap open. Any claim of zero taps would be false, and is not made here.

❓ What is here, and what is not

Here: Dashboard, Compass, Control Panel, Site Map, two working games, a sample Living Nodes Map, Town Hall questions and actions, Help.

Not here yet: live Dots, Pockets, trades, live players, Generosity AI chat, real music, recorded voice-over, Pinboard, seven further games, a live engine sky map, a crisis news feed.

If a button in this package does nothing, that is a bug in this package, not a feature. Every button was checked before this package was pushed — see VERIFY.md in the GitHub folder.

❓ Safety

No phone number, no biometrics, no government registration. No money, no price, no promise, no debt in this front-end. Parental permission openly for the young door. Nobody is tracked. Map nodes are samples, city-level only, no GPS.

This is a game and a meeting engine. It is not a bank, not a wallet, not a promise of earnings, and not a rescue service.
